# FocusPulse - Study Monitor & Concentrator

FocusPulse is a feature-packed, interactive web dashboard designed for students, competitive exam aspirants (MPSC/UPSC/SSC), and professionals to maximize concentration, track study sessions, generate ambient soundscapes, and eliminate distractions.

## ✨ Key Features
- ⏱ **Pomodoro & Custom Concentrator Timer**: 25m Focus, 5m Short Break, 15m Long Break with Web Audio beep alerts.
- 🎧 **Concentration Audio Synthesizer**: Pure Web Audio API synthesized Rain Ambient, White Noise, Ocean Waves, and 10Hz Alpha Binaural Beats.
- 📊 **Real-Time Study Analytics**: Focus minutes today, completed task counter, and daily study streak counter stored in `localStorage`.
- 📋 **Study Subject & Task Tracker**: Plan study topics, mark progress, and delete completed items.
- ⛶ **Focus Mode & Dynamic Theme**: Fullscreen distraction-free UI and dark/light mode toggle.

## 🚀 Live Usage
Open `index.html` in any browser or launch via local web server.
